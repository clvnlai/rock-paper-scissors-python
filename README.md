 Simple Rock, Paper, Scissors using Python CLI

A simple interactive command-line implementation of the classic Rock, Paper, Scissors game built with Python.

## Features include:
- Case-insensitive user input parsing using `.lower()`
- Randomized computer choice using Python's `random` module
- Continuous game loop with clean exit handling (`quit`)

## How to Run
1. Ensure you have Python installed on your machine.
2. Clone or download this repository.
3. Run the script in your terminal:
   ```bash
   python main.py
